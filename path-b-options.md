## Path B must-haves (per candidate)
- [ ] Restrictions allow more than one dwelling (and an RV, if wanted)
- [ ] Legal access easement/frontage adequate for multiple dwellings and fire apparatus
- [ ] Legal-lot status confirmed; county's answer on family splits / multiple dwellings in writing
- [ ] Enough buildable area for N houses + N septic fields + well(s) with required setbacks
- [ ] Electric: multiple meters or service plan confirmed with the utility
- [ ] Water: well permits/limits or public tap confirmed; public-water-system threshold avoided
- [ ] Flood: buildable area outside floodway; elevation/fill rules affordable
- [ ] Financing route identified for the ownership structure (see guide §10)
- [ ] Family co-ownership agreement signed before closing (G9)
